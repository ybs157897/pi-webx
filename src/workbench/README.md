# pi desk · 个人工作台视觉原型

分支：`codex/personal-workbench-prototype`。

三个功能各自独立，仅使用静态示例定布局和风格。日志代表线上日志，问题代表个人 Bug 单，待办代表自己手写的事项。没有关联流程、业务交互、模拟修复、数据持久化或接口请求。按钮禁用、输入框只读，只有页面导航可用。

## 预览

只启动前端即可查看，不需要启动 pi 服务或配置模型：

```sh
npm run dev:web -- --port 5175
```

- `http://127.0.0.1:5175/#/issues`：问题列表与固定详情区。
- `http://127.0.0.1:5175/#/logs`：线上日志筛选区、分布示意图、深色日志阅读区。
- `http://127.0.0.1:5175/#/todos`：个人清单、周历、今日进度和随手记。

本分支默认入口是工作台。原 Agent 界面保留在 `/chat`，已有 `?session=...` 链接仍进入原界面；使用原 Agent 功能需要按仓库原有方式启动后端。

## 视觉基调

- 暖白底 `#f8f9f6`，浅灰绿侧栏 `#f0f2ed`，墨绿主色 `#37634d`。
- 细边框、小圆角，状态使用低饱和色；主要文字深色，次级信息弱化。
- 系统中文字体，编号和日志使用等宽字体，无外部字体请求。
- 共用固定侧栏与顶部位置导航，三个页面保留各自的信息密度。
- 窄屏下导航移到顶部，列表与详情改为纵向排列。

## 文件

- `Workbench.tsx`：公共框架及 URL hash 导航。
- `pages.tsx`：三个独立静态页面。
- `data.ts`：示例 Bug 单、线上日志、个人待办。
- `components.tsx`：状态、优先级、静态按钮与页面标题。
- `workbench.css`：仅作用于工作台的样式与响应式布局。

首页切换位于 `../main.tsx`，原有 Agent 组件和后端未改动。后续接入真实业务时，可按页面分别替换示例内容和静态控件。
