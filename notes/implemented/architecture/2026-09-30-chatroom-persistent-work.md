# 群聊协作与私有执行状态分离

Status: implemented

## 决策与理由
群话题保存公开协作事实，各 Agent 按讨论或任务分工绑定独立 Session，Run 保存单次执行与恢复风险。继续复用 PiHost、模块配置快照、SQLite 和现有业务工具，运行实例可释放而持久身份保留。详见 [聊天室协议](../../../docs/architecture/internal-chatroom.md)。

## 放弃了什么
放弃每条消息新建工作会话加最近正文重构上下文；它丢失执行连续性且制造大量无法关联的会话。放弃一个 Agent 永久共用一条 Session；不同任务会相互污染。放弃把消费成功当工作完成，或中断后盲目重做所有工具；真实文件与外部副作用未必回滚。

## 复活条件
单数据库需要多个宿主同时调度时，增加持久认领租约及写者围栏；当前单进程 FIFO 与运行账本不能代替跨进程执行所有权。
